# Análise Estatística de Testes de Protótipos
Testamos três versões de um novo produto (Protótipos A, B e C) antes do lançamento ao mercado. Cada protótipo foi submetido a uma série de testes para avaliar seu desempenho.


<img width="1071" height="224" alt="prototipo" src="https://github.com/user-attachments/assets/04567b68-5d70-4421-981b-8703b45e33ed" />


🎯 Conclusão Principal
O Protótipo B apresentou o melhor desempenho, com 40% dos sucessos totais, seguido pelo Protótipo C (35%) e Protótipo A (25%).


🔍 Métricas Calculadas
Sucesso: Número absoluto de testes bem-sucedidos por protótipo

Fa (Frequência Acumulada): Soma progressiva dos sucessos

Fr (Frequência Relativa): Proporção de cada protótipo em relação ao total

%: Conversão da frequência relativa para porcentagem
